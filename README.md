## Open-Source Focus

I am building practical, reusable open-source tools for cheminformatics and QSAR, with an emphasis on workflows that researchers and students can apply to real bioactivity data.

- **[chem-curate](https://github.com/hentablihamza/chem-curate)** — Reproducible bioactivity and chemical structure curation pipeline (RDKit standardization, unit harmonization, duplicate aggregation, PAINS/Brenk alerts, and audit reports) for QSAR and ML drug discovery.
- **[qsar-split-bench](https://github.com/hentablihamza/qsar-split-bench)** — Benchmark random, scaffold, Butina cluster, and time splits side by side to measure data leakage and optimistic bias in QSAR and ML drug discovery.
- **[chembl-easy](https://github.com/hentablihamza/chembl-easy)** — Search ChEMBL and download clean, ML-ready bioactivity data, solving common access problems (timeouts and retries, caching, pagination, ambiguous targets, mixed units, duplicate measurements, SMILES search) for students and researchers.
- **[practical-cheminformatics-course](https://github.com/hentablihamza/practical-cheminformatics-course)** — Hands-on 12-notebook course taking students and researchers from RDKit basics to QSAR modeling, honest validation, and virtual screening, each notebook running in Google Colab with one click on small real public datasets.
- **[practical-biopython-course](https://github.com/hentablihamza/practical-biopython-course)** — Hands-on 12-notebook Biopython course for bioinformatics and structural biology, from sequences and NCBI Entrez to BLAST, alignments, phylogenetics, and protein–ligand structures, following the drug target EGFR with real public data, each notebook running in Google Colab with one click.
- **[practical-molecular-dynamics-course](https://github.com/hentablihamza/practical-molecular-dynamics-course)** — Step-by-step 12-notebook molecular dynamics course with OpenMM, MDTraj, and MDAnalysis, from Newton's equations and force fields to thermostats, PME, protein preparation, equilibration, trajectory analysis, free energy landscapes, and protein–ligand MD of EGFR with erlotinib, each notebook running in Google Colab with one click.
- **[docking-made-easy](https://github.com/hentablihamza/docking-made-easy)** — Reproducible AutoDock Vina docking: protein preparation, a search box computed automatically from the co-crystal ligand, ligand preparation from SMILES, batch screening, tidy result tables, and a symmetry-corrected redocking check against the crystal pose (1.15 Å on EGFR/erlotinib, PDB 1M17).
- **[fingerprint-similarity-guide](https://github.com/hentablihamza/fingerprint-similarity-guide)** — Benchmark-backed 12-notebook guide to which molecular fingerprint and similarity metric work best for which task — virtual screening, scaffold hopping, activity cliffs, and nearest-neighbour QSAR — with every number computed from executed code on public data (DUD-E EGFR, ChEMBL, Delaney ESOL), each notebook running in Google Colab with one click.
- **[schrodinger-hpc](https://github.com/hentablihamza/schrodinger-hpc)** — SLURM job scripts and license-free Python tools for running Schrödinger (Glide docking, LigPrep) at scale on academic HPC, with ligand and binding-pocket extraction helpers.
- **[attention-explained](https://github.com/hentablihamza/attention-explained)** — A step-by-step, figure-rich course explaining the attention mechanism and transformers from scratch through NLP, with runnable toy examples you can open in Google Colab.
- **[practical-nlp-course](https://github.com/hentablihamza/practical-nlp-course)** — Hands-on 12-notebook NLP course covering classical text representation, from one-hot vectors and Bag-of-Words through TF-IDF, n-grams, topic models, and word embeddings, up to classic ML text classification and honest evaluation, each notebook running in Google Colab with one click.
